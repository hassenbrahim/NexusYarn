# NexusYarn

NexusYarn is a Distributed, High-Performance engine for real-time data featuring Auto-scaling and load balancing on a scalable Platform.

NexusYarn is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/NexusYarn.git`
2. `cd NexusYarn`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure NexusYarn, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
